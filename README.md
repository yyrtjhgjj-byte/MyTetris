# MyTetris

スマホのブラウザで遊べるテトリスです。`web/index.html` の1ファイルだけで動きます。

## 遊び方

- **公開版**: https://yyrtjhgjj-byte.github.io/MyTetris/
  `main` ブランチに push すると GitHub Actions が自動で公開します
  （Settings → Pages の Source は「GitHub Actions」）。
- **手元で**: `web/index.html` をブラウザで開くだけで動きます。
- iPhone は Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で遊べます。

## 機能

- SRS 回転（壁蹴りあり）、7種1巡、ホールド、NEXT 5個、ゴースト
- ロックディレイ（0.5秒・操作15回までリセット）
- T-Spin / T-Spin Mini、Back-to-Back、REN、全消しの得点
- モード: マラソン（150ライン）、スプリント（40ライン）、ウルトラ（2分）、エンドレス
- 自己ベストの保存、一時停止（アプリを切り替えたときは自動で止まります）

### 演出とごほうび

- ライン消しの破片・紙吹雪・画面の揺れ、RENが続くほど派手になる褒め言葉（NICE → GODLIKE）
- **FEVER**: ライン消しでゲージがたまり、満タンでFEVER突入、そこからラインを6回消すまでスコア2倍（1列でも4列でも1回）
- **ラッキーブロック**: 金色のブロックを含む列を消すとコイン
- **BGM**: コロブチカ（ロシア民謡・パブリックドメイン）をチップチューンで自動演奏。レベルとFEVERでテンポアップ
- **コイン / プレイヤーレベル / 実績 / ログインボーナス**
- **きせかえガチャ**: ブロック8種・背景4種・エフェクト4種（N〜UR、10連はSR以上1枚確定、ダブりはコインで返還）。ゲーム内コインのみで、課金はありません
- 演出が多すぎるときは設定の「演出ひかえめ」で揺れと破片を減らせます

データ（コイン・コレクション・記録）はブラウザの localStorage に保存されます。

## 操作

| スマホのボタン | 盤面ジェスチャー | キーボード | 動作 |
|---|---|---|---|
| ◀ ▶ | 左右ドラッグ | ← → | 移動（長押しで連続） |
| ▼ | 下ドラッグ | ↓ | ソフトドロップ |
| ▲ | 下フリック | Space | ハードドロップ |
| ↻ / ↺ | タップ | ↑・X / Z | 右回転 / 左回転 |
| HOLD | 上フリック | C・Shift | ホールド |
| ⏸ | | Esc・P | 一時停止 |

設定画面で DAS / ARR / ソフトドロップ速度、左利きレイアウト、効果音、振動を変えられます。

## Swift 版について

`Sources/` と `Package.swift` は Tokamak（SwiftWasm）で作りかけた Swift 版です。
公開には使っていませんが、そのまま残してあります。
