# MyTetris

スマホのブラウザで遊べるテトリスです。`web/index.html` の1ファイルだけで動きます。

## 遊び方

- **公開版**: `main` ブランチに push すると GitHub Actions が `gh-pages` ブランチへ公開します。
  リポジトリの Settings → Pages で「Branch: `gh-pages` / `(root)`」を選ぶと
  `https://<ユーザー名>.github.io/MyTetris/` で遊べます。
- **手元で**: `web/index.html` をブラウザで開くだけで動きます。
- iPhone は Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で遊べます。

## 機能

- SRS 回転（壁蹴りあり）、7種1巡、ホールド、NEXT 5個、ゴースト
- ロックディレイ（0.5秒・操作15回までリセット）
- T-Spin / T-Spin Mini、Back-to-Back、REN、全消しの得点
- モード: マラソン（150ライン）、スプリント（40ライン）、ウルトラ（2分）、エンドレス
- 自己ベストの保存、一時停止（アプリを切り替えたときは自動で止まります）

## 操作

| スマホのボタン | 盤面ジェスチャー | キーボード | 動作 |
|---|---|---|---|
| ◀ ▶ | 左右ドラッグ | ← → | 移動（長押しで連続） |
| ▼ | 下ドラッグ | ↓ | ソフトドロップ |
| ▲ | 下フリック | Space | ハードドロップ |
| ↻ / ↺ | タップ | ↑・X / Z | 右回転 / 左回転 |
| HOLD | 上フリック | C・Shift | ホールド |
| ⏸ | | Esc・P | 一時停止 |

設定画面で DAS / ARR / ソフトドロップ速度、左利きレイアウト、効果音、振動を変えられます。

## Swift 版について

`Sources/` と `Package.swift` は Tokamak（SwiftWasm）で作りかけた Swift 版です。
公開には使っていませんが、そのまま残してあります。
